npm run build 按固定顺序依次构建 tui、telemetry、ai、agent、sqlite-node、protocol、client、server、coding-agent；npm run check 同时运行 biome、pinned-deps、shrinkwrap、TS 类型与浏览器冒烟测试；npm run version:{patch,minor,major} 批量升级工作区版本并仅更新 lockfile；npm run release:{patch,minor,major} 调用 scripts/release.mjs 触发完整发布流水线；npm run generate:models 与 hydrate/model-data 驱动 packages/ai 的模型目录生成。
