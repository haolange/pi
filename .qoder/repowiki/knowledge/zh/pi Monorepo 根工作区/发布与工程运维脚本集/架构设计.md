该模块是一组以 Node.js 脚本（.mjs/.ts/.js）和 Shell 脚本组成的工程运维工具集合，按职责划分为若干子域：
- 发布流程：`release.mjs` 作为编排入口，串联 `release-packages.mjs`（筛选非 private 工作区包）、`package-workspaces.mjs`（递归发现 packages/ 下的 package.json）、`publish.mjs`（校验并执行 npm publish --provenance）、`local-release.mjs`、`release-notes.mjs`、`sync-versions.js`。
- 依赖与锁定文件治理：`check-lockfile-commit.mjs` 在 git pre-commit 阶段比对 HEAD 与工作区 `package-lock.json`，仅允许工作区元数据变更或显式 `PI_ALLOW_LOCKFILE_CHANGE=1`；`check-pinned-deps.mjs`、`check-ts-relative-imports.mjs`、`check-browser-smoke.mjs` 分别用于依赖锁定、相对导入与浏览器冒烟测试检查。
- 模型与代码资产：`diff-model-catalog.mjs`、`publish-model-catalog.mjs`、`generate-thinking-capabilities.mjs`、`generate-coding-agent-shrinkwrap.mjs`、`generate-coding-agent-install-lock.mjs` 围绕模型目录与 coding agent 的 shrinkwrap/lock 文件生成。
- 统计与分析：`tool-stats.ts`、`session-context-stats.mjs`、`cost.ts`、`stats.ts`、`edit-tool-stats.mjs`、`read-tool-stats.mjs` 读取 `.pi/agent/sessions` 下的 JSONL 会话日志，聚合工具调用与 bash 命令统计并输出交互式 HTML。
- 构建与打包：`build-binaries.sh`、`create-source-archive.sh`、`update-source-imports-to-ts.sh`、`profile-coding-agent-node.mjs`、`repro-5893-wsl-bash.mjs` 等辅助二进制构建、源码归档、导入迁移与性能分析。
所有脚本通过共享的 `package-workspaces.mjs` 和 `release-packages.mjs` 统一发现工作区，避免硬编码路径；对外仅暴露命令行接口，无持久状态。
