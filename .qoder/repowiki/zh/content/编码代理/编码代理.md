## 简介
本文件为“编码代理”（Pi Coding Agent）的使用与配置文档，面向希望以 CLI 交互、会话管理、工具调用、技能与扩展机制进行代码开发、调试、测试和部署的工程师。内容覆盖：
- CLI 界面与命令选项
- 交互式会话（对话模式、文件操作、命令执行）
- 内置工具集能力概览（读/写/编辑/终端/搜索/列出等）
- 配置文件格式与自定义项
- 扩展机制（自定义工具、技能系统）
- 常见工作流示例（代码审查、Bug 修复、功能开发、测试编写）
- 性能调优建议与最佳实践
- 容器化与安全沙箱配置

## 项目结构
仓库采用多包 monorepo 组织，核心包括：
- coding-agent：交互式 CLI、会话、设置、技能、扩展、主题、提示模板等
- agent：带工具调用与会话状态管理的 Agent 运行时
- ai：统一的多提供商 LLM API（OpenAI、Anthropic、Google 等）
- tui：终端 UI 库
- telemetry：遥测契约与参考实现
- protocol/client/server：RPC 与协议相关

## 核心组件
- 编码代理 CLI：提供交互式、打印、JSON、RPC 四种模式；支持会话分支、压缩、导出/导入、快捷键、消息队列等。
- Agent 运行时：封装消息流、工具执行（并行/串行）、事件订阅、上下文转换、重试与停止策略。
- 统一 LLM 接口：聚合多家提供商，自动鉴权、令牌与成本统计、上下文序列化与跨模型交接。
- 技能系统：按需加载的能力包，遵循 Agent Skills 标准，支持 /skill:name 命令与渐进式披露。
- 扩展系统：TypeScript 模块，可注册工具、命令、快捷键、事件拦截、自定义 UI、状态持久化等。
- 设置与信任：全局与项目级 JSON 设置；项目信任控制是否加载本地资源与扩展。

## 详细组件分析

### CLI 与交互式会话
- 模式：默认交互、打印(-p/--print)、JSON(--mode json)、RPC(--mode rpc)
- 会话：继续最近会话(-c/-resume)、命名(--name)、指定会话(--session)、分叉(--fork)、临时模式(--no-session)
- 模型：--provider、--model、--api-key、--thinking、--models、--list-models
- 工具：--tools、--exclude-tools、--no-builtin-tools、--no-tools
- 资源：-e/--extension、--no-extensions、--skill、--no-skills、--prompt-template、--no-prompt-templates、--theme、--no-themes、--no-context-files
- 其他：--system-prompt、--append-system-prompt、--tui-mode、--verbose、--approve/--no-approve、-h/-v
- 文件参数：@file 将文件内容附加到消息
- 环境变量：PI_CODING_AGENT_DIR、PI_OFFLINE、PI_SKIP_VERSION_CHECK、PI_TELEMETRY、VISUAL/EDITOR 等

交互式编辑器特性：
- 文件引用 @ 模糊搜索、路径补全 Tab、多行 Shift+Enter
- 外部编辑器 Ctrl+G、粘贴图片/文本 Ctrl+V
- Bash 命令 !command 发送输出给 LLM，!!command 仅本地执行
- 消息队列：Enter 提交引导消息，Alt+Enter 提交后续消息，Esc 取消/恢复

#### 会话管理与分支
- 会话以 JSONL 树形结构存储，支持就地分支与回溯

- 压缩：/compact 手动触发；自动压缩在接近或超出上下文限制时触发，保留完整历史以便回溯

## 性能考虑
- 思考级别与预算：通过 thinkingLevel 与 thinkingBudgets 控制深度与 token 预算
- 压缩策略：compaction.enabled/reserveTokens/keepRecentTokens 控制自动压缩阈值与保留范围
- 重试策略：retry.enabled/maxRetries/baseDelayMs/provider.* 控制代理级与提供商级重试
- 传输与超时：transport、httpIdleTimeoutMs、websocketConnectTimeoutMs
- 缓存：PI_CACHE_RETENTION 延长提示缓存（Anthropic 1h、OpenAI 24h）
- 工具执行模式：parallel（默认）提升吞吐；sequential 保证顺序一致性
- 模型选择：--models 限定循环范围，减少切换开销

## 故障排查指南
- 项目信任问题：非交互模式未提示时使用 --approve/--no-approve；检查 ~/.pi/agent/trust.json 与 defaultProjectTrust
- 工具被阻止：扩展 tool_call 钩子可能返回 block/terminate；检查扩展日志与工具白名单
- 会话溢出：启用自动压缩或使用 /compact；查看 compaction 设置
- 网络/代理：设置 httpProxy；离线模式 PI_OFFLINE=1 关闭所有启动网络操作
- 提供商鉴权：确认环境变量或凭据存储；使用 getAuth 诊断鉴权来源
- 传输问题：调整 transport、httpIdleTimeoutMs、websocketConnectTimeoutMs

### 容器化与安全沙箱
- 无内置权限系统：默认以启动用户权限运行
- 三种隔离模式：
  - Gondolin 扩展：主机保留 pi 与提供商认证，内置工具与 ! 命令路由到本地 Linux 微虚拟机

  - OpenShell：在策略控制的沙箱中运行
- 安全注意：扩展与技能可执行任意代码，使用前务必审阅源码
