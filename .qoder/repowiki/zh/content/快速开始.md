## 简介
本指南帮助你在几分钟内运行第一个 Pi 代理会话。你将完成环境准备、安装与构建、配置 API Key（OpenAI、Anthropic、Google 等）、启动交互式会话，并通过常见使用场景（代码生成、调试帮助、文件操作、命令执行）快速体验 Pi 的核心能力。同时提供故障排除与安全最佳实践，确保新手也能顺利上手。

## 详细组件分析

### 环境与安装
- Node.js 版本要求：>= 22.19.0（由引擎声明约束）。
- 安装依赖：在工作区根目录执行 npm install（可加 --ignore-scripts 以跳过生命周期脚本）。
- 构建：npm run build（会刷新模型数据并构建所有包）；离线构建使用 npm run build:offline。
- 开发测试：npm run check 进行 lint/format/type 检查；./test.sh 运行测试（无 API Key 时跳过 LLM 相关用例）。

## 性能注意事项
- 长会话建议使用压缩（/compact）以减少上下文占用，避免超出模型上下文窗口。
- 合理选择思考级别（thinking level）以平衡质量与成本。
- 使用缓存（如 provider 支持的 prompt caching）可降低重复请求成本。
- 在受限环境中优先使用只读工具集（read/grep/find/ls）减少副作用。

## 故障排除指南
- 无法启动或构建失败
  - 确认 Node.js 版本满足要求（>= 22.19.0）。
  - 清理并重新安装依赖：npm ci 或 npm install --ignore-scripts。
  - 使用 npm run build:offline 避免在线拉取模型数据。
- 无法连接提供商
  - 检查环境变量或 auth.json 中的密钥是否正确。
  - 确认网络可达与代理设置（HTTP_PROXY/HTTPS_PROXY）。
  - 使用 /login 重新登录或切换提供商。
- 权限与信任问题
  - 首次进入项目会被询问是否信任该项目；按提示选择或保存决策。
  - 在非交互模式下可通过 --approve/--no-approve 控制一次运行的信任策略。
- 会话与上下文
  - 若上下文过大导致失败，尝试 /compact 或减少上下文文件内容。
  - 使用 /session 查看当前会话信息，必要时切换到历史分支继续。

### 快速命令速查
- 安装与启动
  - 全局安装：npm install -g --ignore-scripts @earendil-works/pi-coding-agent
  - 启动交互：pi
- 配置密钥
  - 环境变量：export ANTHROPIC_API_KEY=... / export OPENAI_API_KEY=... / export GEMINI_API_KEY=...
  - 认证文件：~/.pi/agent/auth.json
  - 交互登录：/login 选择提供商
- 会话与模式
  - 继续最近会话：pi -c
  - 选择会话：pi -r
  - 非交互输出：pi -p "你的提示"
  - RPC 模式：pi --mode rpc
- 模型与工具
  - 切换模型：/model 或 --provider/--model
  - 限制工具：--tools 或 --exclude-tools
  - 只读模式：--tools read,grep,find,ls
